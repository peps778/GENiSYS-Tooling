GENiSYS Notes / SOP integration

1. Copy the NotesSOP folder into:

src/components/NotesSOP/

2. In src/components/GenisysApp.tsx add:

import NotesSOPPage from "../components/NotesSOP";

3. Inside the existing <Routes> add:

<Route path="/notes-sop" element={<NotesSOPPage />} />

4. Add the existing global sidebar item:

label: "Notes / SOP"
path: "/notes-sop"

Do NOT create another BrowserRouter, global sidebar, Astro layout, or application shell.

5. Run:

npm test
npx tsc --noEmit
npm run build

The module is intentionally self-contained and uses local data.
